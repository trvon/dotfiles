# Dotfiles

Personal configuration for an Arch Linux + sway laptop, managed with
[GNU stow](https://www.gnu.org/software/stow/). Each top-level directory is a
stow package whose contents mirror `$HOME`.

## Install

```sh
sudo pacman -S --needed stow
./install.sh -n          # dry run
./install.sh             # link every package
./install.sh sway zsh    # link only some packages
```

`install.sh` runs `stow --no-folding`, so it links individual files and never
whole directories. That keeps generated files (e.g. `~/.config/sway/wallpaper.png`,
`~/.config/kitty/kitty.conf`) and runtime state out of the repo.

To take over a config that already exists live, run `stow --adopt --no-folding -t ~ <pkg>`
and review `git diff` before committing.

## Packages

| Package | Links |
|---------|-------|
| `zsh` | `.zshenv` (env/PATH only), `.zshrc` (interactive), `.zprofile` |
| `tmux` | `.tmux.conf` |
| `sway` | sway config + scripts, `environment.d`, xdg-desktop-portal, mako, swaylock, kanshi, wluma |
| `waybar` | bar config and style |
| `term` | ghostty (main terminal), foot |
| `fontconfig` | `fonts.conf`: `hintslight` rendering + family aliases for fonts whose config name differs from the installed family (e.g. `Fira Code` -> `FiraCode Nerd Font`) |
| `rofi` | `config.rasi` + the adi1090x `type-1` launcher theme used by `$mod+space` |
| `nvim` | LazyVim config, including `lazyvim.json` (enabled extras) and `lazy-lock.json` (pinned plugin versions) |
| `bin` | `~/.local/bin` helper scripts (waybar disk module, EFI re-signing) |
| `pi` | pi coding agent config (see [pi/README.md](pi/README.md)) |

Other directories: `bsd/` (OpenBSD notes and config), `windows/` (Windows notes),
[SERVER.md](SERVER.md) (server/admin notes).

## Secrets

Secrets never go in the repo. API keys and tokens live in
`~/.config/zsh/secrets.zsh` (`chmod 600`, git-ignored), which `.zshenv` sources.
Config files reference them as `$VAR` (e.g. pi's `models.json`).

A gitleaks pre-commit hook in `.githooks/` blocks commits that contain
secrets. Enable it once per clone:

```sh
git config core.hooksPath .githooks
```

## Packages lists

```sh
pacman -Qqen > pkglist.txt       # native explicit packages
pacman -Qqem > pkglist-aur.txt   # AUR / foreign packages
sudo pacman -S --needed - < pkglist.txt
```

## Notes

- **Light/dark theme.** `$mod+t` (or `sway/.config/sway/scripts/auto-theme.sh`)
  flips the whole desktop: GTK, Ghostty, Neovim, waybar, sway borders, mako,
  rofi and swaylock. A daemon re-checks the time of day every 5 minutes, and a
  manual toggle sticks until the next day/night boundary. Generated files are
  live-only and never tracked (like `kitty.conf` and `wallpaper.png`):
  - `~/.config/waybar/theme.css` - `@define-color` palette, imported by `style.css`
  - `~/.config/sway/theme.sh` - bare-hex colours sourced by `lock.sh` / `swaynag-exit.sh`
  - `~/.config/mako/config` - rendered from `sway/.config/mako/config.template`
  - `~/.config/rofi/colors/current.rasi` - copy of `gruvbox-{light,dark}.rasi`
  - `~/.config/sway/.theme-mode` - applied mode + time anchor
  - `~/.config/sway/wallpaper.png` - copy of the chosen wallpaper (also what
    `lock.sh` reads for the lockscreen)
  - `~/.config/sway/.wallpaper-set` - which wallpaper set is in use

  `$mod+Shift+b` cycles wallpaper sets; the sets, their sizes and their licences
  are documented in `sway/.config/sway/wallpapers/README.md`.

  Borders are applied at runtime with `swaymsg client.*` rather than an
  `include`, because a missing `include` hard-fails sway before the generator
  has ever run.
- The Neovim config is the `nvim` stow package. `lazyvim.json` and
  `lazy-lock.json` are tracked on purpose: the former records which LazyVim
  extras are enabled, the latter pins every plugin to a revision. Commit
  `lazy-lock.json` after updating plugins so `:Lazy restore` can reproduce the
  set. Plugins themselves live in `~/.local/share/nvim/lazy`, not in this repo.
- `kitty.conf` is generated by `sway/.config/sway/scripts/auto-theme.sh`.
- User systemd units enabled: pipewire, wireplumber, wluma, gcr-ssh-agent, ssh-tpm-agent.
